# Proposal and seminar presentation

The authoritative proposal for this package is [Proposal_October_2026.pdf](Proposal_October_2026.pdf), the twelve-page supplied October revision. The [twenty-slide seminar PDF](Seminar_Slides_October_2026.pdf) presents the same core/supporting/exploratory structure. The [editable Keynote source](Seminar_Slides_October_2026.key) is included. These files are preserved unchanged; their hashes are recorded in the release manifest.

## Version precedence

1. **October 2026:** daily civic heat response is the core study; vegetation cooling loss is supporting work; allocation is exploratory. A satellite test of the temperature effect of citizen watering is not attempted.
2. **29 September 2026:** the monthly exploratory response protocol and report provide implemented preliminary evidence.
3. **August 2026:** older proposal documents, slide builders, and workstream notes describe a different design, including a conditional watering-to-LST detectability gate. They are historical background, not the current approval request.

## Qualifications to read with the supplied proposal

- **Counts (Section 6.2):** the canonical May 2020–December 2025 linked-and-LOR-assigned sample contains **11,127 distinct trees**, **57,786 events**, and **2,249,502 litres**. The full source snapshot extends through April 2026 and contains 11,278 IDs, of which 11,160 match the inventory. These are different samples. The proposal's 11,087 and 11,245 alternatives are not adopted as the canonical count; their original filters remain unresolved. See the [reconciliation](../preliminary_results.md#sample-reconciliation).
- **Coordinate exclusions:** the full-snapshot coordinate audit flags 125 invalid/outside-Berlin records; the canonical panel links by tree ID and uses inventory geometry. That flag alone is not its exclusion rule. The canonical unmatched/unassigned loss is 688 events.
- **Preregistration:** exploratory monthly, spatial, and equity outcomes have already been examined. Any future registration must disclose that exposure and distinguish genuinely prospective hypotheses, specifications, and held-out evaluation from retrospective exploration. No registration is represented as complete.
- **Novelty and bibliography:** the proposal's broad “first” and “no published method” statements remain literature-review claims to verify, not findings established by this repository. The Berlin heat-mortality citation listed as Burkart et al. should be checked against Schuster, Burkart and Lakes (2014), as already documented in the [literature memo](../../docs/related_literature.md).
- **Appendix A:** the watering-density and detectability calculations are design rationale in the supplied proposal, not a newly reproduced experiment in this package. Its “not recoverable” conclusion should be read as a scoped feasibility judgement, not a proof for every study design.
- **Daily response feasibility:** the available tree-day table contains only days with recorded activity. The balanced area-day panel, young-tree historical denominator, participation controls, and hierarchical daily response fits are planned. In 2024–2025 many timestamps are rounded to midnight UTC, so subdaily timing cannot be recovered.
- **Data availability:** “all data are public” describes the intended design. Several proposed inputs are still absent; the supplied monthly Ortsteil LST file also lacks extraction metadata and an explicit redistribution licence. See the [data guide](../../data/README.md).

These notes preserve the supplied proposal while making the examination record explicit about what has been demonstrated.
