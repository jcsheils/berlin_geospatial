# Active proposal

[Proposal_Refined_October_2026.pdf](Proposal_Refined_October_2026.pdf) is the eighteen-page refined October 2026 proposal that governs new analyses as amended in November 2026 (SHA-256 `b402625faa15bd05bed1feb64d302d9f708245210c533885b8afe592f6cb3142`). It defines RQ1–RQ4, with Part II (RQ1–RQ3) as the core study. Added to the repository on 2 November 2026.

On 3 November 2026, Appendix B was added. It states the exploratory RQ1 pilot, the daily event model and the reported-volume model in full and defines each parameter. The only other changes are a cross-reference in Part II, the date line and two references (Chen and Roth, 2024; Santos Silva and Tenreyro, 2006). The appendix makes explicit some details the main text leaves open, notably how tree stock enters the volume model. The file was re-exported, so line breaks differ slightly from the fourteen-page 2 November copy (SHA-256 `9dfeacfbbb61dc91b127b2f2cb19a2b6482144fddf121e0fd4209262bf27ae8e`).

On 9 November 2026, the [revised research design](../revised_research_design_2026_11.md) amended the proposal. It evaluates citizen watering as co-produced climate adaptation and replaces the proposal's purpose statement and research questions. The proposal remains the reference for data definitions, Appendix A and the RQ1 models in Appendix B. The [active analysis plan](../analysis_plan.md) sets out how the two fit together.
